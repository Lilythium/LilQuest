# LilQuest

LilQuest is a browser-based roguelike adventure game built with SvelteKit.

```sh
npm install
npm run dev
npm test
```

## Layout

- `src/data` contains static content such as classes, races, equipment, enemies, skills, and world definitions.
- `src/game` contains runtime logic for character creation, combat, progression, randomization, runs, saves, and skills.
